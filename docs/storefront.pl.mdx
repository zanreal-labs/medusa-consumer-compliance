Plugin liczy i przechowuje, front sklepu wyświetla. Fragmenty używają Reacta i
`fetch`; w każdym frameworku wygląda to tak samo. `BACKEND` to adres Medusy, a
`KEY` to klucz publikowalny.

## Jedno zapytanie na stronę produktu

```tsx
const res = await fetch(
  `${BACKEND}/store/products/${productId}/compliance?region_id=${regionId}&locale=pl`,
  { headers: { "x-publishable-api-key": KEY } },
);
const compliance = await res.json();
const forVariant = compliance.variants.find((v) => v.variant_id === selectedVariantId);
```

Na stronach list wywołaj raz `/store/consumer-compliance/variants?ids=...` dla
widocznych wariantów.

## Obniżona cena

Cenę odniesienia pokazuj wszędzie, gdzie komunikujesz obniżkę: na kafelkach,
w wynikach wyszukiwania, w polecanych produktach, na stronie produktu i w koszyku
(wyjaśnienia UOKiK).

```tsx
function Price({ price, omnibus }) {
  const pln = (n) => new Intl.NumberFormat("pl-PL", { style: "currency", currency: "PLN" }).format(n);
  const showAsReduced = omnibus.is_reduced && omnibus.reference_price !== null && !omnibus.reference_not_higher;
  if (!showAsReduced) {
    return <span className="price">{pln(price)}</span>;
  }
  return (
    <div className="price price--reduced">
      <span className="price__current">{pln(price)}</span>
      <span className="price__badge">-{omnibus.reduction_percent}%</span>
      <p className="price__reference">
        {omnibus.reference_label_text}: {pln(omnibus.reference_price)}
      </p>
    </div>
  );
}
```

Wynik to na przykład: **80,00 zł** -20% · Najniższa cena z 30 dni przed obniżką:
100,00 zł.

Zasady z wyjaśnień UOKiK, które warto wymusić w komponencie:

- procent i przekreślona cena odnoszą się do ceny odniesienia;
- używaj zwróconej etykiety. „Cena omnibus”, „cena referencyjna”, „było” albo
  gwiazdka z wyjaśnieniem na dole strony nie są zgodne z prawem;
- skrót „Najniższa cena” jest dopuszczalny tylko przy technicznie ograniczonym
  miejscu (kafelki), gdy pełna etykieta jest łatwo dostępna;
- najwyżej dwie lub trzy ceny, w tej samej kolejności w całym sklepie;
- gdy plugin zwraca `reference_not_higher` albo `reason: "no_prior_price"`, nie
  pokazuj ceny jako obniżki.

Kod rabatowy na konkretne produkty wymaga tego samego bloku najpóźniej tam, gdzie
kod jest stosowany, także w koszyku. Wywołaj trasę wariantów z
`reduction_started_at` ustawionym na start promocji.

## Cena jednostkowa i kaucja

```tsx
{forVariant.unit_price && !forVariant.unit_price.same_as_price && (
  <span className="unit-price">
    {pln(forVariant.unit_price.amount)} / {forVariant.unit_price.reference_label}
  </span>

```

## Blok bezpieczeństwa produktu

Pokaż go w samej ofercie, na stronie produktu, a nie tylko w regulaminie.

```tsx
function SafetyBlock({ safety }) {
  if (!safety.applicable) return null;
  const m = safety.manufacturer;
  const r = safety.responsible_person;
  return (
    <section aria-labelledby="gpsr-heading">
      <h2 id="gpsr-heading">Informacje o bezpieczeństwie produktu</h2>
      {m && (
        <p>
          <strong>Producent:</strong> {m.trade_name ?? m.name}, {m.postal_address}, {m.email ?? m.url}
        </p>
      )}
      {r && (
        <p>
          <strong>Osoba odpowiedzialna w UE:</strong> {r.name}, {r.postal_address}, {r.email ?? r.url}
        </p>
      )}
      {safety.product_identifier && <p><strong>Identyfikator:</strong> {safety.product_identifier}</p>}
      {safety.warnings && <p><strong>Ostrzeżenia:</strong> {safety.warnings}</p>}
      {safety.safety_information && <p>{safety.safety_information}</p>}
      {safety.safety_document_urls.map((url) => (
        <a key={url} href={url}>Instrukcja i etykieta</a>
      ))}
    </section>
  );
}
```

## Przycisk odstąpienia

Umieść „Odstąp od umowy tutaj” w widocznym miejscu na liście zamówień i stronie
zamówienia w koncie klienta, a dla zamówień gości także na publicznej stronie
dostępnej ze stopki i z e-maili o zamówieniu. Pokazuj go, dopóki biegnie
którykolwiek termin (`assessment`). Etykieta jest na samym przycisku, a cały
proces dzieje się na jednej stronie.

```tsx
function Withdrawal({ order, email, labels }) {
  const [step, setStep] = useState("start");
  const [pending, setPending] = useState(null);
  const [form, setForm] = useState({ customer_name: "", contact_email: email, items: [] });

  async function request() {
    const res = await fetch(`${BACKEND}/store/consumer-compliance/withdrawals`, {
      method: "POST",
      headers: { "content-type": "application/json", "x-publishable-api-key": KEY },
      credentials: "include",
      body: JSON.stringify({ display_id: order.display_id, email, locale: "pl", ...form }),
    });
    if (res.ok) {
      setPending(await res.json());
      setStep("confirm");
    }
  }

  async function confirm() {
    const res = await fetch(`${BACKEND}/store/consumer-compliance/withdrawals/${pending.withdrawal.id}/confirm`, {
      method: "POST",
      headers: { "content-type": "application/json", "x-publishable-api-key": KEY },
      body: JSON.stringify({ token: pending.confirmation_token }),
    });
    if (res.ok) setStep("done");
  }

  if (step === "start") return <button onClick={() => setStep("form")}>{labels.entry}</button>;
  if (step === "form")
    return (
      <form onSubmit={(e) => { e.preventDefault(); request(); }}>
        {/* name, contact e-mail (pre-filled, editable), item checkboxes with quantities */}
        <button type="submit">Dalej</button>
      </form>
    );
  if (step === "confirm")
    return (
      <div>
        <p>{pending.withdrawal.statement}</p>
        <button onClick={confirm}>{labels.confirm}</button>
      </div>
    );
  return <p>Otrzymaliśmy Twoje oświadczenie. Potwierdzenie wysłaliśmy na {form.contact_email}.</p>;
}
```

Nie wstawiaj między dwa etapy ofert zatrzymujących klienta ani dodatkowych okien.

## Informacje dla konsumenta

Tekst o opiniach pokaż przy bloku opinii, a informację o personalizacji cen przed
złożeniem zamówienia, gdy `used` ma wartość true. Oba pochodzą z
`/store/consumer-compliance/disclosures`.

## Dostępność

Dla ustawy o dostępności liczy się front sklepu: obsługa klawiaturą i widoczny
fokus w procesie odstąpienia i zamówienia, prawdziwe nagłówki i etykiety (jak we
fragmentach), tekst zamiast obrazów tekstu i kontrast zgodny z WCAG 2.1 AA.
